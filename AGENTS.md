# Instruções do projeto

## Design obrigatório

Para qualquer alteração de interface, layout, componente visual, estilo, cor, tipografia, ilustração, copy de interface ou comportamento responsivo, leia e aplique [`docs/design.md`](docs/design.md) antes de editar os arquivos.

Esse documento é a fonte única das definições de design do produto. Reutilize seus tokens e padrões existentes. Se uma mudança estabelecer uma nova decisão visual permanente, atualize `docs/design.md` na mesma alteração.

Ao concluir uma mudança visual, confira desktop e mobile, estados interativos, contraste, foco e possíveis problemas de overflow. No resumo da alteração, mencione a decisão de design relevante ou a seção do guia que foi atualizada.
